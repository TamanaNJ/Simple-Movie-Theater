🎬 My Movie Theater Website

This project is a simple movie theater themed webpage created for Assignment 3. The website displays a cinema-style screen with my name as the theater title and an embedded movie trailer from YouTube. The design uses basic HTML and CSS to create a fun cinema atmosphere with borders, shadows, and a dark background.

The project is built using HTML5 and CSS3. A Google Font is used to improve the text style, and a YouTube video is embedded using an iframe. The layout is centered on the page and works well on different screen sizes.

Through this project, I learned how to structure a webpage using semantic HTML, embed videos from YouTube, center elements using CSS, and apply simple styling such as borders, box shadows, and background gradients. I also learned how to organize files in folders and deploy a website using GitHub Pages.

To run the project, simply open the index.html file in any web browser or view the live version using the GitHub Pages link provided in the submission.
